# DOC: внешние свойства таблиц — следующий этап

## Подтверждённый пробел

Парсер обрабатывает `sprmPHugePapx` (`0x6646`), но пропускает
`sprmPTableProps` (`0x646B`) с предупреждением и использует доступные
inline-свойства. На двух локальных документах обнаружены соответственно 65 и 6
ссылок PTableProps в свойствах абзацев основной области. Это число ссылок,
а не число потерянных таблиц. Личные документы и их содержимое не публикуются.

Одного перехода по ссылке недостаточно: современные свойства могут создавать
ячейки через `sprmTInsert`, который пока не поддерживается. После перехода
нельзя продолжать читать резервные свойства из исходного массива.

## Основание

- [MS-DOC: Tables](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-doc/5b45f0e7-7760-4fdb-af88-0146de2feb4c):
  определения ячеек создаются TDefTable/TInsert и удаляются TDelete;
  резервный TDefTable может предназначаться для старых читателей.
- [MS-DOC: TInsertOperand](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-doc/082d49fd-8f96-4fd9-ac6e-61bd7c00b90d):
  вставка задаёт индекс, число ячеек и ширину; после неё допустимо не более
  63 ячеек и 31680 twips общей ширины.
- [MS-DOC specification](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-doc/ccd7b486-7881-484c-a137-51170af7cc22),
  Paragraph Properties / sprmPTableProps: ссылка ведёт к PrcData в Data,
  cbGrpprl не меньше 10; обработка ссылки заменяет остаток исходной группы.
  Цепочки HugePapx/PTableProps должны завершаться.
- [Разъяснение Microsoft Open Specifications Support](https://learn.microsoft.com/en-us/answers/questions/1458720/conversion-of-irregular-tables-doc-docx):
  приведён путь PAPX → HugePapx → PTableProps → TInsert; отсутствие TDefTable
  в исходном PAPX не означает отсутствия определения строки.

## Порядок реализации и проверки

1. Независимые синтетические группы свойств: TInsert, TDelete и изменение
   ширины после TDefTable, вставки в начало/середину/конец, границы индексов
   и размеров. Учитывать порядок операций и взаимодействие с объединениями.
2. Общий ограниченный обход HugePapx/PTableProps: проверка диапазонов Data,
   длины PrcData, смешанных циклов, глубины и общего бюджета записей.
   Проверить, что резервные inline-свойства после ссылки не применяются.
3. Сквозной собственный DOC с ожидаемыми координатами и объединениями,
   затем сверка локального корпуса без вывода личного текста.
4. Отдельно учитывать условные табличные стили и свойства раскладки:
   поддержка внешних записей сама по себе не подтверждает полноту геометрии.

Эта заметка фиксирует исследование и критерии. Поддержка внешних свойств
таблиц ещё не реализована; текущее предупреждение остаётся.
