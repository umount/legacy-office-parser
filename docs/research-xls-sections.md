# XLS: числовые секции по знаку

## Контракт

Поддерживаем обычные секции положительных, отрицательных и нулевых чисел.
Одна секция применяется ко всем числам. Две означают «положительные и ноль;
отрицательные», три — «положительные; отрицательные; ноль». Дополнительная
четвёртая допускается только как `@`, не меняющий исходный текст ячеек.

Секция выбирается по исходному значению до округления. Отрицательная секция
получает модуль числа; знак или скобки задаются её маской. Поэтому
`0.00;(0.00);"zero"` выводит -12.5 как `(12.50)`, -0.001 как `(0.00)`,
а ноль — как `zero`. Числовое `value` сохраняется без изменения, включая знак.
Текстовое представление может скрывать знак по явному указанию автора:
`0.00;0.00` для -12.5 выводит `12.50`. Для анализа используйте также исходное
значение; текст не заменяет типизированные данные. `General` также допустим
как целая секция; `General;General` для -12.5 даёт `12.5`, что отдельно
подтверждено LibreOffice. В остальном сохранён прежний контракт `str(value)`.

Разделитель — только неэкранированная точка с запятой вне кавычек.
Все секции проверяются до выбора, включая неиспользуемые для текущего числа.
Допустимы прежние числовые ядра и явные подписи; плюс, минус и скобки могут
быть неэкранированными. Знаки экспоненты остаются частью числового ядра.
Нулевая секция может быть непустой подписью в кавычках/escape без числа.

В начале числовой секции допускается один стандартный цвет: Black, Blue,
Cyan, Green, Magenta, Red, White, Yellow (без учёта регистра). Цвет — только
оформление, он не входит в извлекаемые данные. Цветовые индексы, другие
директивы в скобках и сравнения `[>100]` не интерпретируются.

## Ограничения

Общий предел маски остаётся 64 символа, количество секций — не более четырёх.
Пустые/скрывающие секции, произвольная текстовая четвёртая секция, локали,
условия, accounting, масштабируемые запятыми и дробные форматы остаются
неподдержанными: возвращается исходное число с предупреждением. Нельзя
подставить сомнительный формат даже из невыбранной секции. Формулы не
вычисляются; применяются только их сохранённые числовые результаты.
Форматы дат не расширялись. Текст всего результата учитывается лимитами.

## Основания и проверка

[Microsoft: number format sections](https://support.microsoft.com/en-us/excel/review-guidelines-for-customizing-a-number-format)
описывает порядок секций, кавычки, escape и стандартные цвета. Реализация
самостоятельная; библиотеки форматирования не добавлялись.

Авторский `tests/fixtures/xls_sections/sign_sections.xlsx` задаёт точные маски
и значения независимо от парсера. Он нужен только для подготовки тестов,
поддержку XLSX в runtime не добавляет. LibreOffice 7.4.7.2 экспортировал XLS;
отдельный CSV-прогон сверяет девять ожидаемых строк, включая формулу,
скобки, проценты, подпись USD, ноль и точку с запятой внутри подписи.
Исходный OOXML воспроизводим; бинарные метаданные экспортированного XLS могут
отличаться между запусками. API и CLI проверяются отдельно от форматтера.
